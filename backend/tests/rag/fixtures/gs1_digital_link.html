GS1 Digital Link Standard

1. Introduction

GS1 Digital Link enables connections between physical objects and digital information.

The standard extends the role of GS1 identifiers by enabling them to function as web URIs.

2. URI Syntax

The base URI follows the pattern /{primaryIdentifier}/{value}.

Primary identifiers include GTIN, GLN, SSCC, and others defined in section 3.
